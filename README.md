# bom

## App Feature Map

這份 app 目前最接近原本 Excel 日常操作的三張主要資料表是：`帳戶資產`、`持股明細`、`股息收入`。

### 帳戶資產

- 側邊欄點 `帳戶資產`
- 可查看欄位：所有權人、金融機構、帳戶名稱、帳戶類型、資產類型、幣別、投入金額、數量、台幣價值、更新日
- 可操作：
  - 用上方搜尋、篩選、排序查看資料
  - 每列點 `編輯`
  - 進入 modal 後可用 `儲存`、`取消`、`還原`、`關閉`

### 持股明細

- 側邊欄點 `持股明細`
- 可查看欄位：所有權人、證券帳戶、代號、商品名稱、類型、資產類別、區域、數量、平均成本、市價、總成本、市值、預估清算淨值、未實現損益、損益率、預估年配息、預估殖利率、更新日
- 可操作：
  - 用上方搜尋、篩選、排序查看資料
  - 預設隱藏數量小於或等於 0 的已清倉商品，可勾選 `顯示已清倉商品`
  - 用 `顯示欄位` 選擇表格欄位；表格底部依幣別分開彙總成本、市值與清算淨值
  - 每列點 `更新目前資料` 查看或修改持股狀態
  - 更新持股時，`平均成本`輸入值不含買入手續費
  - 每列點 `編輯配息估計` 查看或修改配息估計
  - modal 內可用 `儲存`、`取消`、`還原`、`關閉`

## 持股成本與損益

- `平均成本`與`總成本`已包含買入手續費；編輯持股時輸入的平均成本不含買入手續費。
- `市值`為數量乘市價的毛額。
- `預估清算淨值`會扣除賣出手續費與交易稅；未實現損益與損益率以此金額計算。
- 商品預設買入手續費率為 `0.001425`，賣出手續費與交易稅預設為 `0`。
- 舊持股平均成本已一次性套用 `0.001425` 買入手續費率。每筆持股快照會保存實際套用的買入費率，後續調整商品費率不會回溯改變既有成本。

## 已知限制

- 尚未支援交易或 lot 層級的已實現損益。
- 非台幣持股尚未統一換算為 NTD 報表值。
- 多所有權人帳戶尚未定義資產價值分攤規則。

### 股息收入

- 側邊欄點 `股息收入`
- 可查看區塊：上方 summary 卡片、下方逐筆股息表
- 可查看欄位：所有權人、入帳帳戶、代號、商品、來源、入帳日期、稅前金額、稅額、費用、實收金額、幣別、備註
- 可操作：
  - 點 `＋新增股息`
  - `MANUAL` 列點 `編輯`
  - modal 內可用 `儲存股息` / `更新股息`、`刪除`、`取消`、`還原`、`關閉`
  - modal 內也可點 `＋新增帳戶`、`＋新增商品`

## Related Pages

### 快速市價更新

- 側邊欄點 `快速市價更新`
- 設定 `價格日期`
- 在每列 `新市價` 欄位輸入數值
- 點 `儲存有輸入的價格`

### 匯率維護

- 側邊欄點 `匯率維護`
- 填 `來源幣別`、`匯率日期`、`匯率`、`備註`
- 點 `儲存匯率`

### Excel 歷史股息

- 側邊欄點 `Excel 歷史股息`
- 這頁是唯讀歷史資料
- 用上方篩選與 `清除篩選` 查看資料
